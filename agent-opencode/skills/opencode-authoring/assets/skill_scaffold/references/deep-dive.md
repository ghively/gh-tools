# Deep Dive (rename me)

Reference files hold the depth SKILL.md points to: full option tables, long
procedures, background, edge-case catalogs. The model reads a reference only
when SKILL.md routes it here, so a reference can afford length — but it still
needs structure (headings the router text can name) and it should open with
one line saying when to read it.

If the content can rot (versions, prices, product names), add a banner:

> Last verified: YYYY-MM against <the sources you checked>.

The freshness workflow watches those banners.
